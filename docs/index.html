它能做什么

一句话：让你的 AI 客户端拥有豆包的生图能力，用的是你已经登录的账号。

🔗

无水印直链

从 SSE 里挑 image_raw / dwm3 模板地址，拿到的就是原图直链，不用自己去水印。

🖼️

多图全量返回

服务端一次可能给 1~4 张，全部返回：本地文件路径 + CDN 链接 + 尺寸，结构化解析漏掉的还会按原文补回。

👥

多账号自动排队

默认账号优先、每号并发 1 个任务，全忙就排队而不是失败；停用的账号不参与调度。

📱

MCP 里直接扫码

没有账号时调用 doubao_login，客户端会直接弹出一个扫码窗口，扫完自动保存。

5 个 MCP 工具

stdio 与 streamable HTTP 两种传输都支持，客户端配好即可用。

工具作用
doubao_image文生图 / 图生图，一次生成几张就返回几张（路径 + 链接 + 尺寸）
doubao_login直接从 AI 客户端弹窗扫码登录，不用切到 GUI
doubao_models列出可用模型、32 种风格 key、8 种比例
doubao_ping检查登录态是否有效，也能识别 IP 风控
doubao_accounts账号池：列出 / 切换默认 / 启用 / 停用 / 删除

快速开始

Windows 用 GUI 登录，macOS / Linux 粘贴一次 Cookie 即可，之后都是同一条 MCP 配置。

  1. 下载 windows-x64.zip（ARM 机器选 windows-arm64），解压到任意目录
  2. 双击 doubao-image-mcp.exe
  3. 点账号卡片上的「扫码登录」，用豆包 App 扫一下
  4. 复制界面里「MCP 服务」卡片生成的 JSON，粘进客户端并重启

配置与账号保存在 %APPDATA%\doubao-image-mcp，所以移动或改名 exe 不会丢账号。

  1. 解压后给执行权限，并导入一次登录态
  2. 浏览器按 F12 → Network → 任意 doubao.com 请求 → 复制整段 cookie: 请求头
  3. 把整段 Cookie 粘给 -set-session，之后即可交给 MCP 客户端
unzip doubao-image-mcp-v1.1.0-macos-arm64-cli.zip -d doubao-image-mcp
cd doubao-image-mcp && chmod +x doubao-image-mcp

# 整段 Cookie、Copy as cURL、或者只填 sessionid 都认
./doubao-image-mcp -set-session "sessionid=…; ttwid=…; s_v_web_id=…"

# 客户端拉起时用这条
./doubao-image-mcp -mcp

macOS 首次运行若被 Gatekeeper 拦：xattr -d com.apple.quarantine ./doubao-image-mcp

stdio 模式（推荐，客户端自己拉起进程）：

{
  "mcpServers": {
    "doubao": {
      "command": "C:\\Users\\你\\Downloads\\doubao-image-mcp.exe",
      "args": ["-mcp"]
    }
  }
}

或者常驻 HTTP 模式（一个进程服务多个客户端）：

.\doubao-image-mcp.exe -http 127.0.0.1:8770

# 客户端配置
{
  "mcpServers": {
    "doubao": { "type": "http", "url": "http://127.0.0.1:8770/mcp" }
  }
}

⚠️ HTTP 接口没有鉴权，默认只绑 127.0.0.1，不要改成监听局域网。

常见问题

更多细节见 README。

需要豆包官方 API Key 吗？

不需要。程序用的是你自己在浏览器里登录后的 Cookie，走网页版接口，免费账号就能用 Seedream 5.0 Flash。

会被封号吗？

属于逆向调用网页接口，没有官方保证。程序做了并发限制（每个账号同时只跑一个任务）与自动排队来降低风控概率；请自己控制频率，不要批量刷额度。

为什么 macOS / Linux 没有图形界面？

Wails 的 GUI 依赖 cgo（mac 用 WKWebView，Linux 用 WebKitGTK），无法在 Windows 上交叉编译。所以这两个平台发的是纯 Go 命令行版，MCP 功能完整，只是登录改为粘贴一次 Cookie。

扫码窗口白屏怎么办？

多半是 WebView2 运行时缺失、代理或网络问题。跑一次 doubao-image-mcp.exe -diagnose，报告会生成在配置目录里，含系统版本、WebView2 版本、代理与连通性检测结果。

多个客户端同时用会怎样？

stdio 模式下每个客户端会拉起自己的进程，队列不共享；要严格串行就用 HTTP 模式，由同一个进程统一调度。
